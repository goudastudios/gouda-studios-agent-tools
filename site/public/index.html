Gouda Studios Agent Tools

Clean, low-cost data tools for public government and company records and website contacts, built for people and AI agents. All of them run on Apify. Pay per event, with no platform usage fee added. AI agents can pay per run through Apify agentic payments (x402, Skyfire) with no Apify account, or call the tools with an Apify API token, or through the Apify MCP server at https://mcp.apify.com. One-URL MCP endpoint for all tools: https://gouda-studios-agent-tools.vercel.app/mcp (Streamable HTTP, Apify OAuth or Bearer Apify token).

SAM.gov Contract Opportunities

Get new federal contract opportunities from SAM.gov as clean JSON, no API key needed. Filter by keyword, NAICS, set-aside, notice type, agency and state. Includes deadlines, days left and contracting officer contacts. Monitor mode returns only new notices.

$0.001 per run + $0.002 per opportunity. Apify | JSON

SEC EDGAR Filings

Monitor SEC EDGAR filings by ticker or CIK, including 8-K, 10-Q, 10-K, Form 4 insider trades, Form D and S-1. Each result has the company, form type, filing date and document links. Only-new mode turns it into an alert feed for investors, research and AI agents.

$0.001 per run + $0.002 per filing. Apify | JSON

USAspending Federal Awards

Search USAspending.gov federal awards by keyword, recipient, agency, NAICS, state, date and amount. Get contracts and grants with amounts, recipients, awarding agency and performance dates as JSON. Track competitors, find who won contracts and build sales prospect lists.

$0.001 per run + $0.0015 per award. Apify | JSON

GLEIF Company LEI Lookup

Find any company LEI number by name, or look up an LEI, in the official GLEIF global registry. Get the legal name, status, jurisdiction, registration number, legal and HQ address, and direct and ultimate parent companies. For KYC, KYB, vendor checks and data enrichment.

$0.001 per run + $0.003 per company. Apify | JSON

Website Contact Extractor

Extract emails, phone numbers, social media links and addresses from any list of websites. One clean deduplicated row per site, Cloudflare-protected emails decoded, phones validated, MX checked. Pay only for sites where an email or phone is found.

$0.0005 per run + $0.0025 per website with contacts. Apify | JSON

YouTube Transcript Extractor

Get the transcript of any YouTube video or Short as clean text, timestamped text, segments and SRT. Bulk URLs, any language, auto-translate. Pay only for transcripts you get; failed videos are free.

$0.0005 per run + $0.004 per transcript. Apify | JSON
