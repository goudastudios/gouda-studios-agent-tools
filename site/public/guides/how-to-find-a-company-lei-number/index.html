How to find a company's LEI number

Short answer: Search the GLEIF global LEI registry by the company's legal name, ideally with its country. The Company LEI Lookup tool does this in one call and returns the 20-character LEI, legal name, status, address and parent companies as JSON.

Tool: GLEIF Company LEI Lookup | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Write the company's legal name as precisely as you can, for example "Apple Inc.".
  2. Add the ISO country code of its legal address (US, GB, DE) to narrow matches.
  3. Run the tool with companyNames and country. Exact legal-name matches come first, then fuzzy matches.
  4. Check status and registrationStatus: ACTIVE and ISSUED mean the LEI is current.

Example input

{
  "companyNames": [
    "Apple Inc."
  ],
  "country": "US"
}

FAQ

What is an LEI?

A Legal Entity Identifier is a 20-character code from the ISO 17442 standard that uniquely identifies a legal entity taking part in financial transactions. GLEIF publishes every LEI for free.

Can I search by registration number instead of name?

Yes. Pass registrationNumbers with the company registry number, for example a UK Companies House number, plus the country.

How much does a lookup cost?

$0.003 per company row plus $0.001 per run. There is no subscription.
