How to check if an LEI is valid and find the parent company

Short answer: Look the LEI up in the GLEIF registry and read its registration status, renewal date and parent relationships. The Company LEI Lookup tool returns all of that per LEI, with includeParents turned on by default.

Tool: GLEIF Company LEI Lookup | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Collect the LEIs you need to verify.
  2. Run the tool with leis and includeParents set to true.
  3. Treat registrationStatus ISSUED as valid. LAPSED means the LEI was not renewed.
  4. Read directParent and ultimateParent to see the ownership chain.

Example input

{
  "leis": [
    "HWUPKR0MPOU8FGXBT394"
  ],
  "includeParents": true
}

FAQ

What does a LAPSED LEI mean?

The entity did not renew its LEI on time. The code still identifies the company, but many regulators and banks expect an ISSUED status.

Does every company report a parent?

No. GLEIF records parents only when the entity reports them or files an exception reason.
