Secret Santa gift exchange tracker: draw names, set a budget, and track purchases without spoiling the surprise

Short answer: List every participant once, set one shared budget cap, then assign each giver a recipient with a formula or a one-time random draw. Keep the assignment column hidden from the shared view (or use a private host sheet). Track Bought / Wrapped / Brought for each gift so the host can chase stragglers before the party.

Start with one participant list

One row per person keeps the draw fair and makes it obvious if someone was added twice.

  • A: Name
  • B: Email or phone (for reminders)
  • C: Wishlist link or 3 hint ideas
  • D: Dietary or allergy notes (if the party includes food)
  • E: Attending? (Yes / No / Maybe)
  • F: Assigned recipient (host-only)
  • G: Gift status (Idea / Ordered / Bought / Wrapped / Brought)
  • H: Amount spent ($)
  • I: Notes

Set one budget everyone can see

Put the cap in a single cell (for example Budget!$B$1) and reference it on every reminder. A common office or friend-group range is $15 to $30; family groups often go higher. Write the rule next to the cap: "Stay at or under the cap; experiences and handmade gifts count."

Draw names without double-assigning

Two workable methods:

  • Host shuffle: copy Names into a Recipients column, shuffle that column once, then check that nobody got themselves (A2<>F2). Re-shuffle any self-matches.
  • Spreadsheet formula approach: after the list is final, the host fills F with a derangement (a permutation with no fixed points). Do not share column F in the same sheet participants edit.

Hide the spoilers

Participants need the budget, the party date, and their own assignment — not everyone else's. Options that stay free:

  • Private host tab: keep assignments on a tab only the host opens; message each person their recipient out of band.
  • Individual view: give each person a filtered view or a one-row slip with only their name and recipient.
  • Wishlist column stays public so givers have ideas without asking and ruining the surprise.

Host chase list before the party

Filter Gift status for anything that is not Brought three days before the exchange. Sort by Amount spent blank to catch people who have not shopped. Send one group reminder with the budget cap and the party time; nudge individuals only for missing Brought ticks.

White elephant or Yankee swap variant

If you are doing a white elephant instead of a 1:1 Secret Santa, drop the Assigned recipient column and track: Item brought, Unwrap order (random numbers), Stolen? (Yes/No), Final owner. Keep the same budget cap so the pile stays fair.

Roll it into your full Christmas list

Secret Santa gifts still count toward your overall holiday spend. Copy each Brought gift into your main gift tracker under the recipient's name so one budget view covers office exchanges and family presents together.

FAQ

How do I draw Secret Santa names in a spreadsheet?

List everyone once, shuffle a copy of the names into an Assigned recipient column, then fix any self-matches by swapping. Keep that column on a host-only tab so the surprise is not spoiled.

What is a good Secret Santa budget?

Pick one number the whole group can afford — often $15 to $30 for coworkers or friends. Put the cap in a single cell and repeat it in every reminder.

How do I track who has bought their gift?

Add a Gift status column (Idea / Ordered / Bought / Wrapped / Brought) and filter for anything short of Brought a few days before the party.
