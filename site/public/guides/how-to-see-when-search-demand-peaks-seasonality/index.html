How to see when search demand for a product peaks each year

Short answer: Run the Google Trends Scraper with a 5-year time range. Each keyword row returns the full 0 to 100 timeline plus peakInterest, peakDate and averageInterest, so you can see which weeks demand peaks and plan content, stock or ads before it.

Tool: Google Trends Scraper | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Put the products or topics you sell in searchTerms.
  2. Set timeRange to today 5-y so several yearly cycles show up.
  3. Read peakDate and the interestOverTime timeline to find the weeks demand climbs.
  4. Use interestByRegion to see which states or countries lead, then schedule your launch a few weeks before the peak.

Example input

{
  "searchTerms": [
    "christmas planner",
    "grill"
  ],
  "geo": "US",
  "timeRange": "today 5-y",
  "interestOverTime": true,
  "interestByRegion": true
}

FAQ

How far back does the data go?

Use timeRange all for data from 2004 to the present, or today 5-y for the last five years.

Can I compare several products?

Each keyword is fetched on its own 0 to 100 scale, so compare their shapes and peak dates rather than raw values.

Can I check one US state?

Yes. Set geo to a region code such as US-CA.
