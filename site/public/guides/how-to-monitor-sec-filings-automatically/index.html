How to monitor SEC filings automatically

Short answer: Schedule the SEC EDGAR Filings Feed with your tickers and form types and set onlyNew to true. Each run returns only filings that are new since the last run, with links to the documents on EDGAR.

Tool: SEC EDGAR Filings | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. List the tickers or CIKs you follow.
  2. Choose form types, for example 8-K for material events.
  3. Set onlyNew to true and schedule the actor hourly or daily.
  4. Send new rows to Slack, email or your research database.

Example input

{
  "tickers": [
    "AAPL",
    "TSLA"
  ],
  "formTypes": [
    "8-K"
  ],
  "filedWithinDays": 7,
  "onlyNew": true
}

Use it from an AI agent

Connect any MCP client to https://gouda-studios-agent-tools.vercel.app/mcp, or see the Claude and Cursor guide.

FAQ

Can I monitor all companies, not just a watchlist?

Yes. Leave tickers and CIKs empty and pick at least one form type to get the latest filings market-wide.

Does this respect SEC rate limits?

Yes. The tool uses the SEC public APIs within their fair access limits.
