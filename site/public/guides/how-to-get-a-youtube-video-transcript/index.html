How to get the transcript of a YouTube video

Short answer: Paste the video URL or 11-character ID into the YouTube Transcript Extractor. It returns one row per video with the full transcript as one clean string, timestamped lines, timed segments and optional SRT, plus the title and channel. It costs $0.004 per transcript, and videos without captions are free.

Tool: YouTube Transcript Extractor | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Copy the video link. Watch URLs, youtu.be links, Shorts, live and embed URLs and bare video IDs all work.
  2. Run the tool with videos set to that link. Set languages if you want something other than English.
  3. Read the text field for the whole transcript, or timestampedText and segments if you need timings.
  4. Turn on includeSrt to get a subtitle file you can load into an editor.

Example input

{
  "videos": [
    "https://www.youtube.com/watch?v=UF8uR6Z6KLc"
  ],
  "languages": [
    "en"
  ],
  "includeSrt": true
}

FAQ

Do I need a YouTube API key or a Google login?

No. The tool reads the captions YouTube already publishes, and a residential proxy is built in so YouTube bot checks are handled for you.

What if a video has no captions?

The row comes back with status error and the reason, and you are not charged for it.

Can I get a transcript in another language?

Yes. List language codes in priority order in languages, or set translateTo to use YouTube's own auto-translation when the video offers it.
