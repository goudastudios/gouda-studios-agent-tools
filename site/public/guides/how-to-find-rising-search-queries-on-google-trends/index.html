How to find rising and breakout search queries on Google Trends

Short answer: Run the Google Trends Scraper with your seed keywords and relatedQueries turned on. Each keyword returns a top list of the most searched related queries and a rising list of the fastest-growing ones, where a value of Breakout means growth of more than 5000 percent.

Tool: Google Trends Scraper | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. List your seed keywords, one per search term.
  2. Set geo to a country code such as US or GB and timeRange to the window you care about, for example today 3-m.
  3. Keep relatedQueries on and read the rising list for new keyword ideas.
  4. Repeat each month and compare which queries appear or drop out.

Example input

{
  "searchTerms": [
    "standing desk",
    "ai agents"
  ],
  "geo": "US",
  "timeRange": "today 3-m",
  "relatedQueries": true
}

FAQ

What does Breakout mean on Google Trends?

Google labels a rising query Breakout when its search interest grew by more than 5000 percent against the previous period, usually because the topic is new.

Are Trends values real search volumes?

No. Values run from 0 to 100 and show relative interest, where 100 is the peak for that term, place and time range.
