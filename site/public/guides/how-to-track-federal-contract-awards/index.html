How to track federal contract awards

Short answer: Query USAspending.gov, the official source for federal spending, with your keywords, agencies or NAICS codes and a date range. The USAspending Awards Search tool returns each award with amount, recipient, agency and dates, and its onlyNew mode turns a schedule into an awards feed.

Tool: USAspending Federal Awards | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Pick your filters: keywords, NAICS codes, awarding agencies, states and a minimum amount.
  2. Choose awardType: contracts, idvs, grants, loans, direct_payments or other.
  3. Run once for research, or schedule it daily with onlyNew set to true to get only newly reported awards.
  4. Send the JSON rows to a sheet, CRM or Slack.

Example input

{
  "keywords": [
    "cybersecurity"
  ],
  "awardType": "contracts",
  "startDate": "2026-01-01",
  "minAmount": 1000000
}

FAQ

How current is USAspending data?

Agencies report contract awards within days to weeks of signing, so recent awards appear with a short lag.

Can I filter by NAICS code?

Yes. Pass naicsCodes, for example ["541512"] for computer systems design.
