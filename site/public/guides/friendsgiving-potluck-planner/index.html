Build the potluck signup first

Share one list so guests claim a lane before they cook. Duplicate dishes are the usual Friendsgiving failure mode.

  • A: Guest name
  • B: Dish type (Main / Side / Salad / Dessert / Drink / Other)
  • C: Dish name
  • D: Servings (feeds how many)
  • E: Dietary tags (Vegetarian, Vegan, Gluten-free, Nut-free, Contains nuts, Dairy-free)
  • F: Needs oven / fridge / outlet?
  • G: Confirmed? (Yes / Maybe / No)

Cap each dish type

Before you send the sheet, set soft caps so the table stays balanced.

  • Mains: 1 to 2 (host usually covers one)
  • Sides: about 1 per 3 guests
  • Salads or fresh dishes: 1 to 2
  • Desserts: 1 per 4 to 6 guests
  • Drinks: 1 alcoholic + 1 non-alcoholic option, or BYOB with host providing water and ice

Host buys the shared infrastructure

Guests bring dishes; the host covers what nobody wants to haul.

  • Turkey, ham, or another main if not claimed
  • Plates, cups, napkins, utensils (or ask one guest to bring compostables)
  • Ice, water, coffee or tea
  • Foil, plastic wrap, and a few spare containers for leftovers
  • One backup side or salad in case a Maybe turns into a No

Dietary and allergen pass

Filter the signup by Dietary tags the day before. If two guests need gluten-free and every dessert has crust, ask one person to switch or add a labeled GF option. Put allergen notes on serving cards so people do not have to ask mid-line.

Day-of host timeline

Work backwards from sit-down time. Friendsgiving kitchens are small; oven slots matter more than fancy recipes.

  • T-minus 3 hours: main in the oven if you are roasting
  • T-minus 90 minutes: clear fridge space and set out serving utensils
  • T-minus 60 minutes: guests start arriving with cold dishes; park oven-needed dishes in a queue
  • T-minus 30 minutes: reheat sides in batches; put drinks and ice out
  • Sit-down: mains and hot sides first, desserts later
  • After: pack leftovers with names so guests take their own containers home

FAQ

When should I send the Friendsgiving potluck signup?

About 10 to 14 days ahead is enough time for people to claim a dish type and change plans once. Send a reminder three days before with the caps and who still has an open lane.

How much food per person for a potluck?

A rough host check is that claimed servings should add up to at least 1.25x the guest count across mains and sides combined, because some dishes under-deliver and some guests eat light.
