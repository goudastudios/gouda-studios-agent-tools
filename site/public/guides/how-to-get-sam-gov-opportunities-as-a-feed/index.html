How to get SAM.gov opportunities as a feed

Short answer: Schedule the SAM.gov Contract Opportunities tool daily with your filters and onlyNew set to true. Each run returns only the notices that were not in the previous run, so you get a clean feed without duplicates and without a SAM.gov API key.

Tool: SAM.gov Contract Opportunities | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Set your filters: keywords, naicsCodes, setAsides, noticeTypes and states.
  2. Turn on onlyNew.
  3. Create a daily schedule for the actor in Apify, or call it on a timer from your own code or agent.
  4. Route the new rows to email, Slack, a sheet or a CRM with an Apify integration or webhook.

Example input

{
  "keywords": "software",
  "naicsCodes": [
    "541511",
    "541512"
  ],
  "onlyNew": true,
  "maxResults": 50
}

Use it from an AI agent

Connect any MCP client to https://gouda-studios-agent-tools.vercel.app/mcp, or see the Claude and Cursor guide.

FAQ

Do I need a SAM.gov API key?

No. You can add your own key in apiKey for higher rate limits.

Which notice types are included?

All of them by default. Use noticeTypes codes to narrow it, for example o for solicitations and r for sources sought.
