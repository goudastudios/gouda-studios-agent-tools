How to track insider trading (Form 4) filings

Short answer: Insiders report trades on SEC Form 4. Run the SEC EDGAR Filings Feed with formTypes ["4"] and your tickers, with onlyNew on, to get each new insider filing with a direct link to the document.

Tool: SEC EDGAR Filings | Run it on Apify | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Add your watchlist tickers.
  2. Set formTypes to ["4"].
  3. Turn on onlyNew and schedule the actor.
  4. Open the linked document to read the transaction details.

Example input

{
  "tickers": [
    "NVDA",
    "MSFT",
    "AMZN"
  ],
  "formTypes": [
    "4"
  ],
  "onlyNew": true
}

Use it from an AI agent

Connect any MCP client to https://gouda-studios-agent-tools.vercel.app/mcp, or see the Claude and Cursor guide.

FAQ

How fast are Form 4s filed?

Insiders must file within two business days of the trade.

Can I add Form 144 or 13D?

Yes. Add those form types to formTypes, for example "144" or "SC 13D".
