Gouda Studios Agent Tools

How to use SAM.gov, SEC EDGAR, USAspending and LEI data in Claude or Cursor with MCP

Short answer: Add https://gouda-studios-agent-tools.vercel.app/mcp as a remote MCP server (Streamable HTTP). Your client signs in with your Apify account through OAuth, or you pass an Apify API token as a Bearer header. The four tools then appear in the client and you pay per result.

Tools: SAM.gov Contract Opportunities (Apify) | SEC EDGAR Filings (Apify) | USAspending Federal Awards (Apify) | GLEIF Company LEI Lookup (Apify) | MCP: https://gouda-studios-agent-tools.vercel.app/mcp

Steps

  1. Cursor: add the server to .cursor/mcp.json as {"mcpServers":{"gouda-studios":{"url":"https://gouda-studios-agent-tools.vercel.app/mcp"}}}.
  2. Claude: add a custom connector with the URL https://gouda-studios-agent-tools.vercel.app/mcp.
  3. Other clients: use the same URL with Streamable HTTP transport, and either OAuth or an Authorization: Bearer header with your Apify token.
  4. Ask a question, for example "find open SBA set-aside software RFPs on SAM.gov" or "what is the LEI for Siemens AG".

Example input

{
  "mcpServers": {
    "gouda-studios": {
      "url": "https://gouda-studios-agent-tools.vercel.app/mcp"
    }
  }
}

Use it from an AI agent

Connect any MCP client to https://gouda-studios-agent-tools.vercel.app/mcp, or see the Claude and Cursor guide.

FAQ

Do I need an Apify account?

For MCP use, yes, a free Apify account. Agents can also pay per run without an account through x402 or Skyfire on the Apify API.

Which tools are included?

SAM.gov Contract Opportunities, SEC EDGAR Filings Feed, USAspending Awards Search and Company LEI Lookup, plus Apify helper tools to fetch run results.
