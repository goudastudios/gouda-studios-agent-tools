USPTO Trademark Phrase Screener

Screen a list of phrases against the public USPTO trademark search (no login, no API key). Returns exact and close wordmarks with serial number, live/dead status, international classes, and flags for any live mark in class 25 or 16. $0.001 per phrase.

Open on Apify: gouda_studios/uspto-trademark-screener

Use cases

  • Print on demand and merch sellers screening phrases before they upload designs
  • Flagging live marks in class 25 (clothing) and class 16 (paper goods) for a phrase list
  • Brand and product teams doing a first pass on name ideas before a full legal search
  • AI agents checking whether a phrase already has live USPTO wordmarks

Pricing

  • Actor start: $0.00005 per run
  • $0.001 per phrase returned ($1.0 per 1,000)
  • No platform usage fee. Use phrases to cap spend.

Input parameters

NameTypeDefaultDescription
phrasesarrayPhrases or design names to screen, one per line, e.g. plant mom, just one more chapter.
maxMarksPerPhraseinteger200How many exact and close wordmarks to list. Counts and the live class 25/16 flags still use the full hit set.
includeDeadbooleantrueIf false, listed marks are live only. Dead counts are still reported.
