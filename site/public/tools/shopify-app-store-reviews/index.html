Shopify App Store Reviews

Scrape Shopify App Store reviews by handle, with the ratings[] filter, store name, country, time using the app and developer replies. Also returns listing rating, review count, pricing plans and launch date, plus a category listing mode. No login or proxy. $0.00002/review.

Open on Apify: gouda_studios/shopify-app-store-reviews

Use cases

  • Shopify app developers tracking reviews, ratings and developer replies for their app and rivals
  • Founders sizing a Shopify app category before they build
  • Agencies and investors comparing ratings, review counts and pricing plans across a category
  • AI agents summarizing merchant complaints for a Shopify app

Pricing

  • Actor start: $0.00005 per run
  • $0.00002 per review returned ($0.02 per 1,000)
  • $0.0002 per category app listing
  • No platform usage fee. Use maxReviewsPerApp to cap spend.

Input parameters

NameTypeDefaultDescription
appHandlesarrayOne app per line: a handle (klaviyo-email-marketing) or an apps.shopify.com URL. Leave empty if you only want the category listing mode.
maxReviewsPerAppinteger200How many reviews to return per app. 0 means all public reviews (paginated). Default 200.
starFilterarrayOptional list of star ratings, passed to the Store as ratings[] (e.g. [1, 2] for one- and two-star reviews). Leave empty for all ratings.
categoryUrlstringOptional. A Shopify App Store category URL or slug (e.g. marketing-and-conversion-social-trust-product-reviews or the full /categories/.../all URL). Returns one listing row per app with name, rating and review count. Parent categories crawl subcategory /all pages.
maxAppsInCategoryinteger100Maximum app listing rows to return when Category URL is set.
phrasesarrayOptional phrases. Adds one free keywordSummary row per app with case-insensitive counts over reviews at or below Low-star max. Counts cover only the reviews returned in this run, not estimates.
lowStarMaxinteger3Phrase counts use reviews with this rating or lower. Ignored if Phrases is empty.
includeSummarybooleantrueAdds one uncharged row with the listing rating, review count, launch date, pricing plans, and the rating distribution of the reviews returned.

How to call

Apify API (synchronous, returns dataset items)

curl -X POST "https://api.apify.com/v2/acts/gouda_studios~shopify-app-store-reviews/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"appHandles": ["klaviyo-email-marketing"], "maxReviewsPerApp": 200, "starFilter": [1, 2], "phrases": ["support", "price"]}'

Apify MCP server

Connect an MCP client to https://mcp.apify.com and add the actor gouda_studios/shopify-app-store-reviews, for example https://mcp.apify.com/?tools=gouda_studios/shopify-app-store-reviews.
