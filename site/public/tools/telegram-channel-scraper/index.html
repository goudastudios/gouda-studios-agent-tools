Telegram Channel Scraper

Scrape public Telegram channels without login or API keys. Get posts with text, date, views, reactions, links, photos, videos and forwards, plus subscriber counts. Date filter, keyword search, full history paging. $0.0003 per post.

Open on Apify: gouda_studios/telegram-channel-scraper

Use cases

  • Crypto, news and OSINT researchers monitoring public Telegram channels
  • Marketers tracking views, reactions and subscriber growth for channels in their niche
  • Building datasets of channel posts with links, media and forwards
  • AI agents summarizing what a public Telegram channel posted recently

Pricing

  • Actor start: $0.00005 per run
  • $0.0003 per post returned ($0.3 per 1,000)
  • $0.001 per channel info
  • No platform usage fee. Use maxPostsPerChannel to cap spend.

Input parameters

NameTypeDefaultDescription
channelsarrayPublic channel usernames, @handles or t.me links, e.g. durov, @telegram, https://t.me/s/durov
maxPostsPerChannelinteger50Newest posts first. Use 0 to fetch only channel info.
postsNewerThanstringOptional ISO date or datetime (UTC), e.g. 2026-11-01. Stops paging when older posts are reached.
searchQuerystringOptional. Returns only posts matching this keyword (Telegram's own in-channel search).
includeChannelInfobooleantrueAdds one row per channel with title, description, verified flag, subscribers and media counts.

Example input

{
  "channels": [
    "durov",
    "telegram"
  ],
  "maxPostsPerChannel": 50,
  "postsNewerThan": "2026-11-01"
