Gouda Studios Agent Tools

Instagram Reels, TikTok and Podcast Transcripts

Transcripts with timestamps for Instagram Reels, TikTok, podcast RSS feeds and any audio/video file URL (mp3, m4a, mp4, wav). Native TikTok captions first, built-in Whisper speech-to-text for the rest. Optional speaker labels (who said what). No login, no API key.

Open on Apify: gouda_studios/instagram-tiktok-transcript-scraper

Use cases

  • Creators and marketers studying the hooks and scripts of top Reels and TikToks
  • Turning short videos and podcast episodes into posts, notes and newsletters
  • RAG pipelines and datasets built from spoken social and podcast content
  • AI agents that need what a Reel, TikTok or audio file actually says, with timestamps

Pricing

  • Actor start: $0.0005 per run
  • $0.002 per caption transcript returned ($2.0 per 1,000)
  • $0.006 per AI speech-to-text transcript
  • $0.003 per extra speech-to-text minute
  • No platform usage fee. Use maxVideos to cap spend.

Input parameters

NameTypeDefaultDescription
videoUrlsarrayInstagram Reel/post links, TikTok video links (including vm.tiktok.com short links), direct audio/video file URLs (mp3, m4a, mp4, wav, webm, ogg), and podcast RSS feed URLs (the latest episodes are transcribed). An Instagram profile link is treated as a username.
instagramUsernamesarrayTranscribe the most recent video posts and reels of public Instagram accounts. Best effort: Instagram returns up to about 12 recent posts without login.
maxReelsPerProfileinteger6How many recent videos to take from each username. Without login Instagram only exposes the latest ~6 posts of a profile (photos are skipped), so you may get fewer.
maxEpisodesPerFeedinteger5For podcast RSS feed URLs, how many of the newest episodes to transcribe.
speechToTextstring"auto"Instagram has no public captions, so Instagram transcripts always use speech-to-text unless this is Off.
sttModelstring"base"Open-source Whisper models running inside the actor. Same price for both.
maxTranscribeSecondsinteger180Longer videos and episodes are transcribed up to this length and marked truncated: true. Up to 1800 seconds (30 minutes).
languagestringISO code like en, es, de. Leave empty to auto-detect. Also picks the matching TikTok caption track when several exist.
includeSegmentsbooleantrueAdds segments: [{start, end, text}] in seconds.
includeSrtbooleanfalseAdds the transcript as an SRT subtitle string.
speakerLabelsbooleanfalseDetects the different voices and labels every segment Speaker 1, Speaker 2, ... Adds speakerTranscript (one line per speaker turn), speakerCount and talk time per speaker. No extra charge for the labels. They need the audio, so TikToks are then transcribed by AI speech-to-text (AI transcript price) instead of captions. Best for podcasts, interviews and multi-person videos.
numSpeakersinteger0Only used with speaker labels. Set it when you know how many people talk (for example 2 for an interview) for more accurate labels. 0 = detect automatically.
maxVideosinteger500Safety cap.
proxyConfigurationobjectOptional. By default the actor connects directly and falls back to a built-in residential proxy when a platform blocks it.
