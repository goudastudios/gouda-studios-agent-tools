Chrome Web Store Reviews

Scrape Chrome Web Store reviews past the 500-review cap. Give extension IDs and optional star filters; get rating, date, text, language, version and helpful votes, plus user count, average rating and current version. Free low-star phrase counts. No login or proxy. $0.0001/review.

Open on Apify: gouda_studios/chrome-web-store-reviews

Use cases

  • Extension developers reading every review past the 500 review cap
  • Competitor research on low-star reviews to find what users want fixed
  • Tracking user count, rating and version changes for a list of extensions
  • AI agents summarizing complaints and feature requests for a Chrome extension

Pricing

  • Actor start: $0.00005 per run
  • $0.0001 per review returned ($0.1 per 1,000)
  • No platform usage fee. Use maxReviewsPerExtension to cap spend.

Input parameters

NameTypeDefaultDescription
extensionIdsarrayOne extension per line: a 32-character ID (e.g. cjpalhdlnbpafiamejdnhcphjbkeiagm) or a chromewebstore.google.com / chrome.google.com/webstore URL.
maxReviewsPerExtensioninteger200How many reviews to return per extension. 0 means all public reviews (paginated past 500). Default 200.
starFilterarrayOptional list of star ratings to keep, e.g. [1, 2] for one- and two-star reviews only. Leave empty for all ratings.
phrasesarrayOptional phrases. Adds one free keywordSummary row per extension with case-insensitive counts over reviews at or below Low-star max. Counts cover only the reviews returned in this run, not estimates.
lowStarMaxinteger3Phrase counts use reviews with this rating or lower. Ignored if Phrases is empty.
includeSummarybooleantrueAdds one uncharged row with the Store user count, average rating, rating count, current version, and the rating distribution of the reviews returned.
