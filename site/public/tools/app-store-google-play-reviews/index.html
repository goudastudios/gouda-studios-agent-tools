App Store and Google Play Reviews

Scrape app reviews from the Apple App Store and Google Play in one run. Give an app name, URL, ID or package and get ratings, review text, dates, versions and developer replies from both stores in one clean JSON schema. No login, no proxy.

Open on Apify: gouda_studios/app-store-google-play-reviews

Use cases

  • Product and growth teams tracking what users say about their app and competitors on both stores
  • Support teams finding bugs and complaints right after a release
  • Market researchers mining review text for feature requests and pain points
  • AI agents summarizing app sentiment from one clean review schema

Pricing

  • No actor start fee
  • $0.0001 per review returned ($0.1 per 1,000)
  • No platform usage fee. Use maxReviewsPerStore to cap spend.

Input parameters

NameTypeDefaultDescription
appsarrayOne app per line: an app name (e.g. Spotify), an App Store URL or numeric ID, or a Google Play URL or package name (e.g. com.spotify.music). The matching app in the other store is found automatically.
storesstring"both"Which store(s) to scrape.
maxReviewsPerStoreinteger100Apple's public review feed returns up to 500 reviews per country. Google Play supports up to 5,000.
sortstring"newest"Review order.
countrystring"us"Two-letter store country code, e.g. us, gb, de, in.
languagestring"en"Two-letter language code for Google Play reviews.
includeSummarybooleantrueAdds one uncharged row with the store rating, rating count and the rating distribution of the returned reviews.

Example input

{
  "apps": [
    "Spotify"
  ],
  "stores": "both",
  "maxReviewsPerStore": 100,
  "sort": "newest",
  "country": "us",
  "language": "en"
}

How to call

Apify API (synchronous, returns dataset items)

curl -X POST "https://api.apify.com/v2/acts/gouda_studios~app-store-google-play-reviews/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"apps": ["Spotify"], "stores": "both", "maxReviewsPerStore": 100, "sort": "newest", "country": "us", "language": "en"}'

Apify MCP server

Connect an MCP client to https://mcp.apify.com and add the actor gouda_studios/app-store-google-play-reviews, for example https://mcp.apify.com/?tools=gouda_studios/app-store-google-play-reviews.
