Merch Marketplace Counts

For each merch keyword, return result counts and the top 20 listing titles and URLs from Redbubble, plus TeePublic, Etsy and Amazon Merch shirt counts when those sites allow datacenter access. Blocked marketplaces are flagged, never guessed. $0.002 per keyword.

Open on Apify: gouda_studios/merch-marketplace-counts

Use cases

  • Print on demand sellers checking how crowded a shirt or sticker niche is before they design
  • Merch researchers comparing Redbubble, TeePublic, Etsy and Merch by Amazon counts for a keyword list
  • Pairing with a trademark screen to shortlist phrases that are both safe and under-served
  • AI agents that score merch ideas by competition with real marketplace counts

Pricing

  • Actor start: $0.00005 per run
  • $0.002 per keyword returned ($2.0 per 1,000)
  • No platform usage fee. Use keywords to cap spend.

Input parameters

NameTypeDefaultDescription
keywordsarrayPhrases or merch keywords, one per line, e.g. christmas cat shirt.
maxListingsinteger20How many top listing titles and URLs to return for each marketplace that is reachable.
marketplacesarray["redbubble", "teepublic", "etsy", "amazonMerch"]Which stores to query. Amazon is a Merch-by-Amazon shirt count when the filter is accepted; otherwise the general search count is returned and flagged.

Example input

{
  "keywords": [
    "christmas cat shirt",
    "plant mom"
  ],
  "maxListings": 20,
  "marketplaces": [
    "redbubble",
    "teepublic",
    "etsy",
    "amazonMerch"
  ]
}
