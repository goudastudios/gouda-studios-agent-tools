SEC EDGAR Filings

New SEC EDGAR filings by ticker, CIK or form type from the official SEC APIs: form, filing date, 8-K items, company, SIC and direct document links. Change-only monitoring mode.

Open on Apify: gouda_studios/sec-edgar-filings-feed

Use cases

  • Investors and analysts watching 8-Ks and insider Form 4s for a watchlist
  • AI research agents that need what a company filed this week as JSON
  • Deal, IR and compliance teams tracking Form D raises, S-1s and 13D stakes

Pricing

  • Actor start: $0.001 per run
  • $0.002 per filing returned ($2.0 per 1,000)
  • No platform usage fee. Set maxResults to cap spend.

Input parameters

NameTypeDefaultDescription
tickersarray[]Optional stock tickers, e.g. ["AAPL","NVDA"]. Resolved to CIKs with the SEC ticker file.
ciksarray[]Optional SEC Central Index Keys, e.g. ["320193"]. Leave tickers and CIKs empty to get latest filings across all companies.
formTypesarray[]Form types to include, e.g. ["8-K","10-K","10-Q","4","D","S-1","13F-HR","SC 13D"]. Empty = all forms (company mode only; market-wide mode needs at least one).
filedWithinDaysinteger7Only filings from the last N days. 0 = no limit (company mode returns the ~1000 most recent).
onlyNewbooleanfalsetrue = skip filings delivered by an earlier run with the same tickers/CIKs/forms. Use with a schedule for an alert feed.
maxResultsinteger100Maximum rows (1-5000). You pay per row, so this caps cost: 100 rows = $0.20.
contactEmailstringOptional. SEC asks automated clients to identify themselves; this email is sent in the User-Agent header to sec.gov only.

{

How to call

Apify API (synchronous, returns dataset items)

curl -X POST "https://api.apify.com/v2/acts/gouda_studios~sec-edgar-filings-feed/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["AAPL", "TSLA"], "formTypes": ["8-K", "10-Q"], "filedWithinDays": 30, "maxResults": 50}'

Apify MCP server

Connect an MCP client to https://mcp.apify.com and add the actor gouda_studios/sec-edgar-filings-feed, for example https://mcp.apify.com/?tools=gouda_studios/sec-edgar-filings-feed.

Agentic payments (x402 / Skyfire)

This actor is eligible for Apify agentic payments, so an AI agent can pay per run without an Apify account. See Apify x402 docs.
