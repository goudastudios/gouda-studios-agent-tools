Website Contact Extractor

Extract emails, phone numbers, social media links and addresses from any list of websites. One clean deduplicated row per site, Cloudflare-protected emails decoded, phones validated, MX checked. Pay only for sites where an email or phone is found.

Open on Apify: gouda_studios/website-contact-extractor

Use cases

  • Sales and agency teams turning a list of company domains into emails, phones and social profiles
  • Local business lead lists: clinics, law firms, contractors, restaurants
  • CRM enrichment with one clean row per company website
  • AI agents that need a company's official contact details as JSON

Pricing

  • Actor start: $0.0005 per run
  • $0.0025 per website with contacts returned ($2.5 per 1,000)
  • No platform usage fee. Set maxResults to cap spend.

Input parameters

NameTypeDefaultDescription
startUrlsarrayWebsites or domains to extract contacts from, one per line. Examples: https://www.example.com or example.com. Each site becomes exactly one output row.
maxPagesPerSiteinteger8How many pages to read on each site, starting with the homepage and then the most likely contact pages (Contact, About, Team, Impressum, Support). You pay per site, not per page, so higher values only cost more time.
defaultCountrystring"US"Two-letter country code used to read local phone numbers that have no +country prefix, e.g. US, GB, DE, AU.
checkMxbooleantrueAdds a free DNS check that each email domain can receive mail. Flags typos and dead domains.
respectRobotsTxtbooleantrueSkip pages that a site's robots.txt asks crawlers not to visit.
proxyConfigurationobject{"useApifyProxy": false}Optional. Most business sites work without a proxy. Turn on Apify Proxy if many sites time out or block requests.

Example input

{
  "startUrls": [
    "https://apify.com",
    "python.org"
  ],
  "maxPagesPerSite": 8,
  "defaultCountry": "US"
}

How to call

Apify API (synchronous, returns dataset items)

curl -X POST "https://api.apify.com/v2/acts/gouda_studios~website-contact-extractor/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://apify.com", "python.org"], "maxPagesPerSite": 8, "defaultCountry": "US"}'

Apify MCP server

Connect an MCP client to https://mcp.apify.com and add the actor gouda_studios/website-contact-extractor, for example https://mcp.apify.com/?tools=gouda_studios/website-contact-extractor.
