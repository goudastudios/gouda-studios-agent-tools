Adobe Stock Keyword Gap Scanner

Scan Adobe Stock keyword saturation (total, photo, video, generative-AI share) and expand seeds into Adobe related searches plus Google autocomplete. No login. About $0.002 per keyword. 30/90-day new-upload counts are not publicly available.

Open on Apify: gouda_studios/adobe-stock-keyword-gap-scanner

Use cases

  • Stock photographers and videographers finding keywords with demand but few existing assets
  • Generative AI contributors checking how saturated a topic already is with AI images
  • Expanding seed keywords into Adobe related searches and Google autocomplete ideas
  • AI agents planning a stock content calendar from real result counts

Pricing

  • Actor start: $0.00005 per run
  • $0.002 per keyword returned ($2.0 per 1,000)
  • $0.0005 per suggestion batch
  • No platform usage fee. Use keywords to cap spend.

Input parameters

NameTypeDefaultDescription
modestring"both"scan = result counts per keyword (gap scanner). expand = Adobe related searches + Google autocomplete from each seed. both = run scan then expand on the same keyword list.
keywordsarrayKeywords to scan and/or seeds to expand, e.g. walking pad, home office, autumn leaves.
usePublicReaderFallbackbooleantrueIf stock.adobe.com returns a Datadome/captcha block (common on some datacenter IPs), retry the same public search URL through the free r.jina.ai reader. No paid proxy is used. Turn off to fail instead.
requestDelayMsinteger400Polite pause between Adobe Stock page fetches. For ~200 keywords, 400 ms keeps a weekly run short and cheap.
