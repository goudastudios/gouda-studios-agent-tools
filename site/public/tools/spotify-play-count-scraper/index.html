Spotify Play Count Scraper

Get exact Spotify play counts for any track, album, artist or playlist. Returns stream counts per track, album totals, artist monthly listeners, followers, world rank, top cities and top tracks. No login, no proxy, $0.001 per track.

Open on Apify: gouda_studios/spotify-play-count-scraper

Use cases

  • Labels, managers and A&R teams tracking exact stream counts for tracks and albums
  • Artists checking monthly listeners, followers, world rank and top cities
  • Music marketers measuring campaign impact on play counts over time
  • AI agents answering how many plays a song or album has on Spotify

Pricing

  • Actor start: $0.00005 per run
  • $0.001 per track play count returned ($1.0 per 1,000)
  • $0.002 per artist profile
  • No platform usage fee. Use maxTracksPerInput to cap spend.

Input parameters

NameTypeDefaultDescription
startUrlsarrayTrack, album, artist or playlist links (open.spotify.com/...) or URIs (spotify:track:...). Mix types freely.
maxTracksPerInputinteger500Caps how many track rows each album or playlist returns.
includeAlbumSummarybooleantrueFor album inputs, also output one album row with total play count across all tracks (not charged).

Example input

{
  "startUrls": [
    "https://open.spotify.com/album/1NAmidJlEaVgA3MpcPFYGq",
    "https://open.spotify.com/artist/06HL4z0CvFAxyc27GXpf02"
  ],
  "maxTracksPerInput": 50
}

How to call

Apify API (synchronous, returns dataset items)

curl -X POST "https://api.apify.com/v2/acts/gouda_studios~spotify-play-count-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://open.spotify.com/album/1NAmidJlEaVgA3MpcPFYGq", "https://open.spotify.com/artist/06HL4z0CvFAxyc27GXpf02"], "maxTracksPerInput": 50}'

Apify MCP server

Connect an MCP client to https://mcp.apify.com and add the actor gouda_studios/spotify-play-count-scraper, for example https://mcp.apify.com/?tools=gouda_studios/spotify-play-count-scraper.
