YouTube Video, Channel, Search and Comments Scraper

YouTube data in one actor: video details, channel videos, shorts, keyword search, channel search by keyword, playlists and comments. Views, likes, publish date, tags, subscribers, channel video counts. $0.30/1K videos, $2/1K channels. No API key, no proxy.

Open on Apify: gouda_studios/youtube-video-channel-scraper

Use cases

  • Creators and agencies researching top videos, views and likes for a topic
  • Finding YouTube channels by keyword with subscribers, video counts and external links
  • Pulling comments and replies for sentiment and audience research
  • AI agents that need YouTube video, channel or comment data as JSON without an API key

Pricing

  • Actor start: $0.00005 per run
  • $0.0003 per video returned ($0.3 per 1,000)
  • $0.0003 per comment
  • $0.002 per channel
  • No platform usage fee. Use maxTotalResults to cap spend.

Input parameters

NameTypeDefaultDescription
videoUrlsarrayYouTube video links (watch, youtu.be, shorts, live) or 11-character video ids. Returns full details for each.
channelsarrayChannel @handles, channel URLs or UC... channel ids. Lists the latest videos from each channel.
channelTabsarray["videos"]Which channel tabs to list.
maxVideosPerChannelinteger30Newest first.
searchQueriesarrayKeywords to search on YouTube.
maxResultsPerQueryinteger30Top results per query, in YouTube order.
sortBystring"relevance"Relevance or most viewed first.
uploadedWithinstring"any"Only videos uploaded within this window.
playlistUrlsarrayPublic playlist links or playlist ids.
maxVideosPerPlaylistinteger100Videos taken from each playlist.
fullDetailsbooleantrueFor channel, search and playlist results, also fetch likes, comment count, exact publish date, tags, category, description and chapters. Turn off for faster, lighter rows. Same price either way.
maxTotalResultsinteger0Hard cap on charged rows for the whole run.
channelSearchQueriesarrayKeywords to find matching YouTube channels (like YouTube search filtered to Channels). Each result is one channel row with channel id, name, @handle, URL, subscriber count, video count, description, avatar, verified flag and external links.
maxChannelsPerQueryinteger20Channels returned per keyword, in YouTube order.
channelSearchDetailsbooleantrueAlso open each found channel to add its video count, full description and keywords. Same price either way.
channelSearchAboutbooleantrueAlso read each found channel's About panel to add external links (website, Instagram, X and others), country, joined date and total channel views. Same price either way. Needs Channel details on.
commentVideoUrlsarrayYouTube video or Shorts URLs (or 11-character ids). Returns top comments with text, author, likes, reply count, hearted flag and comment link.
maxCommentsPerVideointeger100Comments are returned in YouTube top-comments order.
maxRepliesPerCommentinteger00 skips replies. Replies are returned as rows with type reply and parentCommentId.
