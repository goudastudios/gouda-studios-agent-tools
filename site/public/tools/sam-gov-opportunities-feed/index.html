SAM.gov Contract Opportunities

Get new federal contract opportunities from SAM.gov as clean JSON, no API key needed. Filter by keyword, NAICS, set-aside, notice type, agency and state. Includes deadlines, days left and contracting officer contacts. Monitor mode returns only new notices.

Open on Apify: gouda_studios/sam-gov-opportunities-feed

Use cases

  • Small businesses and 8(a), HUBZone, SDVOSB and WOSB firms watching set-asides in their NAICS codes
  • Bid and capture teams building a daily opportunity pipeline
  • GovCon consultants running alerts for many clients
  • AI agents answering which federal RFPs are open for a capability

Pricing

  • Actor start: $0.001 per run
  • $0.002 per opportunity returned ($2.0 per 1,000)
  • No platform usage fee. Set maxResults to cap spend.

Input parameters

NameTypeDefaultDescription
keywordsstringOptional free-text search over SAM.gov notice titles and text, e.g. "cybersecurity" or "janitorial services". Leave empty to return all notices that match the other filters.
naicsCodesarray[]Optional list of 6-digit NAICS industry codes (strings), e.g. ["541511","541512"]. A notice matches if it has any of them. Empty = all industries.
noticeTypesarray[]Optional list of notice type codes: o=Solicitation, k=Combined Synopsis/Solicitation, p=Presolicitation, r=Sources Sought, s=Special Notice, a=Award Notice, u=Justification, i=Intent to Bundle, g=Surplus sale. Empty = all types.
setAsidesarray[]Optional small-business set-aside codes, e.g. ["SBA","8A","SDVOSBC","WOSB","HZC"]. Empty = any set-aside or none.
statesarray[]Optional 2-letter US state codes for the place of performance, e.g. ["VA","MD"]. Requires includeDetails=true. Empty = all locations.
agencyContainsstringOptional case-insensitive text the agency path must contain, e.g. "Navy" or "Veterans Affairs".
postedWithinDaysinteger0Only notices posted or updated in the last N days. 0 = no date limit. Use 1-7 for daily/weekly monitoring.
minDaysUntilResponseintegerOptional. Skip notices whose response deadline is fewer than N days away, so you only get ones you can still bid on.
activeOnlybooleantruetrue (default) = skip archived/inactive notices.
includeDetailsbooleantruetrue (default) = fetch each notice for NAICS, PSC, set-aside, place of performance, full description and contacts. false = faster, fewer fields.
includeContactsbooleantruetrue (default) = include the contracting officer work name, email and phone published on the notice.
onlyNewbooleanfalsetrue = return only notices not delivered in an earlier run with the same filters (state is kept between runs). Use with a schedule for an alert feed.
maxResultsinteger100Maximum rows to return (1-10000). You are charged per row returned, so this caps the cost: 100 rows = $0.20 at $0.002/row.
apiKeystringOptional. Your own free api.sam.gov public API key; when set, the Actor reads the official SAM.gov Opportunities API instead of the public search feed.
