ATS Jobs Scraper

Get every open job from company career sites on Greenhouse, Lever, Ashby, Workable, SmartRecruiters and Workday in one clean JSON schema. Give a company name, careers URL or website and the ATS is detected for you. Salaries, remote type, departments, full descriptions. $1 per 1,000 jobs, no proxy.

Open on Apify: gouda_studios/ats-jobs-scraper

Use cases

  • Job boards and newsletters pulling fresh openings from Greenhouse, Lever, Ashby, Workable, SmartRecruiters and Workday
  • Sales teams using hiring as a buying signal for target accounts
  • Recruiters and job seekers monitoring new roles at a company list every day
  • AI agents answering who is hiring for a role, with salaries and remote type

Pricing

  • Actor start: $0.00005 per run
  • $0.001 per job returned ($1.0 per 1,000)
  • No platform usage fee. Use maxJobsTotal to cap spend.

Input parameters

NameTypeDefaultDescription
companiesarrayOne per line: a company board name (stripe, openai), a careers page URL (https://jobs.lever.co/palantir, https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite) or a company website (figma.com). The ATS is detected automatically.
keywordsarrayKeep only jobs whose title or description contains any of these words. Leave empty for all jobs.
titleKeywordsarrayKeep only jobs whose title contains any of these words, e.g. engineer, sales.
locationsarrayKeep only jobs whose location contains any of these, e.g. New York, Remote, Germany.
remoteOnlybooleanfalseKeep only jobs marked remote.
postedWithinDaysintegerKeep only jobs posted in the last N days. Great for daily new-job monitoring. Jobs without a date are kept.
withSalaryOnlybooleanfalseKeep only jobs where a salary range was published or found in the description.
atsPlatformsarrayOptional. Only look on these platforms.
includeDescriptionbooleantrueAdds plain-text and HTML descriptions. Turn off for faster, smaller runs.
maxJobsPerCompanyinteger1000Cap on jobs returned per company.
maxJobsTotalinteger0Stop after this many jobs across all companies. 0 means no limit.
includeSummarybooleantrueOne uncharged row per company with the detected ATS, board name and job count.

{
