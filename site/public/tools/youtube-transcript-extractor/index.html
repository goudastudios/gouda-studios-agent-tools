YouTube Transcript Extractor

Get the transcript of any YouTube video or Short as clean text, timestamped text, segments and SRT. Bulk URLs, any language, auto-translate. Pay only for transcripts you get; failed videos are free.

Open on Apify: gouda_studios/youtube-transcript-extractor

Use cases

  • AI agents and LLM apps that summarize or answer questions about YouTube videos
  • Content teams repurposing videos and Shorts into posts, newsletters and blogs
  • RAG pipelines and datasets built from spoken content
  • Exporting SRT subtitles for editing and accessibility

Pricing

  • Actor start: $0.0005 per run
  • $0.004 per transcript returned ($4.0 per 1,000)
  • No platform usage fee. Set maxResults to cap spend.

Input parameters

NameTypeDefaultDescription
videosarrayWatch URLs, youtu.be links, Shorts, live or embed URLs, or bare 11-character video IDs.
languagesarray["en"]Language codes in priority order, e.g. en, es, de. If none match, the first available transcript is returned.
translateTostringLanguage code to auto-translate the transcript into using YouTube's translation, e.g. en.
preferManualbooleantrueUse manually created captions over auto-generated ones when both exist.
includeSegmentsbooleantrueAdd an array of segments with start time and duration.
includeSrtbooleanfalseAdd an SRT subtitle file as a string.
maxVideosinteger1000Stop after this many videos.
proxyConfigurationobject{"useApifyProxy": false}Optional. Leave off to use our built-in residential proxy, included in the price. Set your own only if you want to.

Example input

{
  "videos": [
    "https://www.youtube.com/watch?v=UF8uR6Z6KLc"
  ],
  "languages": [
    "en"
  ],
  "includeSrt": false
}

FieldTypeDescription
videoIdstringYouTube video ID

title['string', 'null']Video title
channel['string', 'null']Channel name
channelUrl['string', 'null']Channel URL
statusstringok or error
languageCodestringTranscript language code
languagestringTranscript language name
isGeneratedbooleanTrue for auto-generated captions
translatedTo['string', 'null']Translation target if requested
wordCountintegerWords in transcript
durationSecondsnumberEnd time of last caption
textstringFull transcript as one string
timestampedTextstringTranscript lines prefixed with [m:ss]
segmentsarrayTimed caption segments {start, duration, text}
srtstringSRT subtitles (if requested)
availableLanguagesarrayAll caption tracks on the video
errorstringWhy the video failed (not charged)
